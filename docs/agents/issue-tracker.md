# Issue tracker

Issues for this project live in GitHub Issues: https://github.com/solarisjon/phoenixv3/issues

## Using the issue tracker

- **Create issues**: `gh issue create`
- **Reference in commits**: `fixes #123` closes the issue
- **Link in PRs**: mention issue number in PR description

## External PRs as requests

This repo does not accept external PRs as feature requests. Use GitHub Issues to propose work.
